# Ragas Adapter

Use Ragas when the workflow depends on retrieval.

Best fit:

- SOP Q&A
- maintenance manual Q&A
- product knowledge assistants
- support knowledge-base answers
- technical documentation search

Use Ragas to separate:

- retrieval quality
- context relevance
- groundedness
- answer usefulness

This is especially useful for manufacturing, industrial, energy, and B2B support workflows where the failure is often not "bad writing" but missing or wrong source context.
