# DeepEval Adapter

Use DeepEval when a project needs Python-native LLM tests.

Best fit:

- engineering teams
- pytest-style workflows
- custom metrics
- LLM-as-judge rubrics
- agent, RAG, and chatbot evals

ProcessBench benchmark packs can translate into:

- test cases
- expected output criteria
- custom metrics
- hard blockers
- CI-ready evaluation scripts

Use this adapter after the business pack is clear. Do not start with DeepEval when a promptfoo config is enough.
