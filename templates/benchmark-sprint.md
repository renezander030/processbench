# Benchmark Sprint Template

## Goal

Prove whether a model, prompt, setting, or vendor improves one real business workflow.

## Inputs Needed

- workflow owner
- workflow description
- 20 to 50 representative examples
- current AI output if available
- current acceptance criteria
- known failure examples
- business constraints

## Sprint Steps

1. Select one workflow.
2. Define the decision the benchmark must support.
3. Convert real examples into anonymized test cases.
4. Define pass, fail, warning, and human-review outcomes.
5. Run the current baseline.
6. Run alternatives.
7. Score outputs.
8. Identify regressions.
9. Recommend rollout, hold, split-routing, or further testing.

## Final Deliverables

- benchmark fixture set
- scoring rubric
- comparison report
- regression list
- recommended model or setting
- human-review routing rule
- next benchmark candidates
